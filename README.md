# ⚽ Football Betting Simulator Using Python

A console-based football match simulation game built with Python, combining random number generation, probability, time-based events, and interactive betting mechanics.

Start with 100 virtual tokens, predict whether Team A, Team B, or a draw will be the final result, and test your prediction as the match unfolds. Every 5 seconds, a new match event is generated, including goals, yellow cards, red cards, attacks, and scoring chances. If the match is tied after 90 simulated minutes, the game automatically proceeds to extra time.

## ✨ Features

- ⚽ **Random Match Events:** Simulates unpredictable football action using Python's `random` module.
- ⏱️ **Time-Based Simulation:** Uses `time.sleep()` to control match progression.
- 🎯 **Three Betting Options:** Predict a Team A win, Team B win, or a draw.
- 💰 **Virtual Token System:** Start with 100 tokens and manage your bets.
- 🏆 **Reward System:** Earn a 3× payout for a correct team prediction or a 2× payout for a correct draw prediction.
- 🟨 **Match Statistics:** Tracks goals, yellow cards, and red cards for both teams.
- ➕ **Extra Time:** Simulates an additional 30 minutes when the score is tied after normal time.
- 🔄 **Replay Functionality:** Play multiple matches while maintaining your token balance.
- 🛡️ **Input Validation:** Handles invalid betting choices and bet amounts.

## 🛠️ Tech Stack

- **Language:** Python
- **Modules:** `random`, `time`
- **Concepts:** Variables, loops, conditional statements, user input, exception handling, probability, and arithmetic operations.

## 🎮 How to Run

1. Clone or download this repository.
2. Make sure Python 3 is installed.
3. Open the project folder in your terminal.
4. Run the Python file:

   `python football_betting_simulator.py`

5. Follow the on-screen instructions and place your virtual bets.

## 🎯 Project Objective

This project was developed to apply fundamental Python programming concepts in a practical, interactive game. It demonstrates how randomness, probability, loops, and conditional logic can work together to simulate a simplified football match.

**Note:** This is an educational simulation using virtual tokens only. It does not involve real-money betting or actual football match data.
